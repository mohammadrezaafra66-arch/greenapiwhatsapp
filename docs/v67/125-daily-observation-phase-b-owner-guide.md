# راهنمای مالک — گزارش روزانه مشاهده

## ورود

1. باز کردن UI روی پورت Compose پیش‌فرض: `http://<host>:3002/`
2. منو: **گزارش‌ها و تحلیل** → **گزارش روزانه مشاهده**
3. یا از کارت داشبورد: **مشاهده گزارش روزانه کامل**
4. مسیر مستقیم: `/observation-report`

## کار روزانه

حدود ۰۹:۳۰ تهران این صفحه را باز کنید. نتیجه کلی را بخوانید. اگر «شواهد ناکافی» یا «نیازمند بررسی» است، تنظیمات را تغییر ندهید و گزارش را برای بررسی فنی بفرستید. اگر وضعیت عادی و بدون نقض ایمنی است، Observation را ادامه دهید.

## معنی Status

- معتبر بر اساس شواهد موجود = PASS داده‌ای (هنوز پذیرش نهایی Phase 7 نیست)
- نامعتبر = FAIL
- نیازمند بررسی فنی = REVIEW_REQUIRED
- شواهد ناکافی = INSUFFICIENT_EVIDENCE

Day 14 به‌معنی `PHASE 7 FULLY ACCEPTED` نیست. پذیرش فقط پس از Completion Audit است. Phase 8 تا آن زمان مسدود است.
