# راهنمای نهایی مالک — گزارش روزانه مشاهده

## صفحه کجاست؟

- آدرس: `http://localhost:3002/observation-report`
- منو: `گزارش روزانه مشاهده`
- از داشبورد: `مشاهده گزارش روزانه کامل`

## هر روز چه ساعتی باز کنم؟

بعد از ساعت **۱۰:۰۰ تهران** (پس از ساخت خودکار گزارش روز قبل در حدود **۰۹:۳۰ تهران** / **۰۶:۰۰ UTC**).  
کمتر از یک دقیقه کافی است.

## در یک نگاه چه ببینم؟

1. وضعیت روز (معتبر / نامعتبر / نیازمند بررسی / شواهد ناکافی)  
2. کارت «امروز چه کاری باید انجام دهم؟»  
3. Stop Conditions  
4. اینکه آیا شواهد Runtime و Static جداگانه نمایش داده شده‌اند  

## معنی وضعیت‌ها

- **PASS / معتبر:** این روز بر اساس شواهد موجود قابل‌شمارش است. تنظیمات را تغییر ندهید.  
- **FAIL / نامعتبر:** روز نامعتبر است. خودتان Session را Restart نکنید.  
- **REVIEW_REQUIRED:** نیاز به بررسی فنی. Phase 8 همچنان مسدود است.  
- **INSUFFICIENT_EVIDENCE:** شواهد کافی نیست. این روز را PASS حساب نکنید.

## چرا ممکن است PASS صادر نشود؟

سیستم عمداً وقتی نمی‌تواند Mutation عملیاتی را به‌صورت نسبت‌داده‌شده به Shadow ثابت کند، PASS نمی‌دهد.  
این محافظت است، نه خرابی صفحه.

## Snapshot چیست؟

ثبت زمان‌دار وضعیت مشاهده Shadow. پیام نمی‌فرستد و سیستم واقعی را عوض نمی‌کند.

## شواهد Runtime چیست؟

شواهد همان روز از Snapshotها، پوشش دوره‌ای، Cutover و سلامت زیرساخت.

## شواهد Static چیست؟

اثبات معماری/نسخه release و تست‌های isolation. به‌تنهایی برای PASS کافی نیست.

## Stop Condition چیست؟

هشدارهای ایمنی برای مالک (مثلاً Cutover روشن، نقض پرچم، Scheduler ناسالم).  
صفحه خودش چیزی را متوقف نمی‌کند.

## چه زمانی هیچ کاری نکنم؟

وقتی Observation در حال جمع‌آوری است و Stop Condition فعال نشده — فقط ادامه دهید.

## چه زمانی برای بررسی فنی بفرستم؟

وقتی FAIL یا REVIEW_REQUIRED می‌بینید، یا Stop Condition «فعال شده» است.

## چرا خودم Restart نکنم؟ / Flag تغییر ندهم؟

Restart و تغییر Flag بدون تصمیم رسمی می‌تواند پنجره Observation را خراب کند.

## Day 14 چیست؟

پایان تقویم ۱۴ روزه برای **Completion Audit** است، نه پذیرش خودکار Phase 7.

## Phase 8 چه زمانی مجاز است؟

فقط پس از Completion Audit رسمی Session 2 و تصمیم صریح مالک. این صفحه Phase 8 را باز نمی‌کند.

## نکته مهم

تکمیل این Owner Change (ابزار گزارش) به‌معنی تکمیل Phase 7 یا شروع Phase 8/11 نیست. Observation Session 2 همچنان ادامه دارد.
