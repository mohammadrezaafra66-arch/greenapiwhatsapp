# راهنمای مالک — گزارش روزانه مشاهده (Phase C)

## صفحه و آدرس

- منو: `گزارش روزانه مشاهده`
- مسیر: `/observation-report`
- از کارت داشبورد: `مشاهده گزارش روزانه کامل`

صفحه فقط‌خواندنی است (GET). هیچ دکمه Start/Stop/Restart/Run ندارد.

## معنی وضعیت‌ها

- **PASS / معتبر:** روز بر اساس شواهد Runtime و Static موجود قابل‌شمارش است.
- **FAIL / نامعتبر:** روز نامعتبر است. بدون تصمیم مالک Session را Restart نکنید.
- **REVIEW_REQUIRED:** نیازمند بررسی فنی. Phase 8 مسدود است.
- **INSUFFICIENT_EVIDENCE:** شواهد کافی نیست. روز را PASS حساب نکنید.
- **NOT_APPLICABLE:** خارج از پنجره Session 2.

## شواهد Runtime چیست؟

داده‌های روز از Snapshotها، Cutover، پوشش دوره‌ای، سلامت زیرساخت، و نمونه همبستگی run_id.

## شواهد Static چیست؟

Manifest نسخه release، SHA مستقر، ارجاع تست‌های isolation / send_gate / no-mutation.

## چرا Static-only برای PASS کافی نیست؟

چون معماری درست بودن کد را ثابت می‌کند، نه اینکه در آن روز خاص Mutation عملیاتی رخ نداده باشد.

## گزارش خودکار

- هر روز **06:00 UTC** (حدود **09:30 تهران**)
- برای روز کامل‌شده قبلی UTC
- فقط Log + فایل عملیاتی؛ بدون پیام واتساپ/ایمیل

## کار روزانه مالک

1. صفحه گزارش را باز کنید.
2. وضعیت روز و Stop Conditions را بخوانید.
3. اگر INSUFFICIENT یا REVIEW: تنظیمات را تغییر ندهید؛ در صورت نیاز گزارش را برای بررسی فنی بفرستید.
4. اگر FAIL با Cutover/نقض پرچم: Session را خودتان Restart نکنید.

## چه زمانی هیچ کاری نکنید

وقتی Observation در حال جمع‌آوری است و Stop Condition فعال نشده — فقط ادامه دهید.
